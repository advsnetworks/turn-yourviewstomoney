TURN YOUR VIEWS TO MONEY — SIMPLE NETLIFY VERSION

This version uses a built-in smart sales assistant. It does NOT use Anthropic, OpenAI, an API key, a server, or a Netlify Function.

HOW TO DEPLOY
1. Rename index.html if necessary (it is already named index.html).
2. Upload the site folder to Netlify using Deploy manually, or connect it to a Git repository.
3. No environment variables or API keys are required for the assistant.
4. Replace YOUR_SELAR_CHECKOUT_URL in index.html with your real Selar checkout URL.

NOTE
The assistant is rule-based: it recognizes common questions and gives prepared answers from the product information. It is not a generative AI model, but it is fast, free to run, and works on static hosting.
